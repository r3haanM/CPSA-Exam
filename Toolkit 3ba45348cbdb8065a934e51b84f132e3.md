### CISCO

A Cisco phone configuration filename often looks like:

```
SEP001122334455.cnf.xml
```

Break it down:

```
SEP
↓
Selsius Ethernet Phone

001122334455
↓
Phone's MAC address

.cnf.xml
↓
Configuration file
```
