| | |
| :--- | :--- |
| **Certification** | CREST Practitioner Security Analyst (CPSA) |

## 📚 Exam Structure

<details>
<summary><b>▶ How the exam works</b></summary>

* 120 multiple choice questions, all must be answered.
* 2 hours to complete the exam.
* You need **60%** to pass, which is **72 correct answers**.
* **No negative marking**, so never leave a question blank. Always guess.
* Questions test both **theory** and **practical knowledge**.
* You can flag questions and return to them.
* Some questions describe a scenario or show command output, and you pick the correct interpretation.

</details>

<details>
<summary><b>▶ Syllabus areas</b></summary>

| Area | What to expect |
| :--- | :--- |
| **Soft skills and management** | Engagement lifecycle, scoping, legal and ethical issues, reporting |
| **Core technical skills** | IP protocols, network architecture, common services |
| **Information gathering** | Passive and active recon, DNS, OSINT |
| **Networking** | TCP/IP, routing, switching, wireless basics |
| **Web technologies** | HTTP, cookies, sessions, common web attacks |
| **Operating systems** | Windows and Linux/Unix security, permissions, services |
| **Databases** | SQL basics, common database weaknesses |
| **Vulnerability assessment** | Scanning, interpreting results, false positives |
| **Exploitation concepts** | Common attack techniques and defences |

</details>

<details>
<summary><b>▶ Question styles</b></summary>

* **Knowledge recall**: ports, protocols, standards
* **Scenario based**: "What would you do next?"
* **Output reading**: interpret Nmap, packet captures, logs
* **Best answer**: more than one option may seem right

</details>

## 🔬 Topic Checklists

<details>
<summary><b>▶ Networking</b></summary>

* [ ] OSI and TCP/IP models
* [ ] Common ports and services
* [ ] Subnetting and CIDR
* [ ] TCP handshake and UDP behaviour
* [ ] ARP, DHCP, DNS, ICMP
* [ ] Firewalls, NAT, VLANs

</details>

<details>
<summary><b>▶ Web</b></summary>

* [ ] HTTP methods and status codes
* [ ] Cookies, sessions, tokens
* [ ] OWASP Top 10
* [ ] SQL injection, XSS, CSRF
* [ ] Authentication and access control flaws

</details>

<details>
<summary><b>▶ Operating systems</b></summary>

* [ ] Linux file permissions and users
* [ ] Windows users, groups, and registry basics
* [ ] Active Directory concepts
* [ ] Common misconfigurations
* [ ] Privilege escalation basics

</details>

## 📝 Exam Day Tips

* Read each question twice before answering.
* Flag hard questions and come back to them.
* Answer every question, since there is no negative marking.
* Eliminate wrong answers first.
* Check ID and booking requirements the day before.
