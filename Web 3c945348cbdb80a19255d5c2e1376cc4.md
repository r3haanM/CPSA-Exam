# Web

---

### Status Codes

```pascal
403 → Forbidden
     "I understand your request,
      but you are not allowed."

405 → Method Not Allowed
     "This URL exists, but this HTTP method
      isn't permitted."

410 → Gone ✅
     "This resource has permanently disappeared."

302 → Found / historically "Moved Temporarily"
     temporary redirect

307 → Temporary Redirect
     modern explicit temporary redirect
```
